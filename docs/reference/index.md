# API reference

These pages are generated from the docstrings. `import femforge as ff` exposes the curated names the femforge pages list, and each page documents one module group. The workbench ships as the separate `femforge-workbench` distribution.

| Package | Install extra | What it covers |
| --- | --- | --- |
| `femforge` | none; `femforge[viz]` for Viz and Validation | Config, geometry, meshing, Elmer solves, runs, artifacts, telemetry and results |
| `femforge_workbench` | `femforge[workbench]` | The interactive workbench: serving, the catalogue, the dock, panels, widgets and the theme |
