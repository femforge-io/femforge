# Security policy

## Supported versions

| Version | Security fixes |
| --- | --- |
| Latest 0.x minor version | Yes |
| Older versions | No |

## Reporting a vulnerability

Report a vulnerability privately. Do not open a public issue. Use one of these channels:

- [Private vulnerability reporting](https://github.com/femforge-io/femforge/security/advisories/new) on GitHub
- Email to [security@femforge.io](mailto:security@femforge.io)

Include the following in your report:

- The femforge version
- Your operating system, Python version, and how you run Elmer (native or Docker)
- The smallest script or sequence of steps that reproduces the vulnerability
- The impact, such as code execution or data exposure

## What to expect

- We acknowledge your report within seven days.
- After triage, we follow up with a fix or a mitigation plan.
- We credit you in the changelog unless you prefer otherwise.
